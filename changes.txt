        version 0.1.0                   6 oct 2026

+ first version of web port of BK Emulator for Windows 3.7 (WebAssembly)
+ emulation core (devemu) compiled to wasm32-wasi: K1801VM1 CPU, all board models,
  screen, sound devices, tape, floppy controllers, HDD, state files (.msf);
  MFC replaced by small compatibility layer (CString, CFile, CArray)
+ BK-0010-01 starts on page: Monitor + Vilnius Basic 1986 (colour screen)
+ bk.ini of original emulator used as is; ROM images loaded from rom/
+ Stop / Start, Reset, zoom (Fit, 1x .. 3x, 4:3 picture), full screen, About
+ page checks for newer build (home-screen apps on iPhone / iPad)

        version 0.11.0                  8 oct 2026

  / slave). Enter in File Commander or drop on screen mounts image, drive is asked;

        version 0.12.0                  8 oct 2026

+ tapes .tap (BK Emulator format) and .wav: played as a real cassette, BK reads them
  through port 177716 (BK-0011 too; EMT 36 emulation is off meanwhile). Enter in File
  Commander or drop on screen shows the tape's file (name, address, length, checksum);
  Load (BK-0010, + 32K, + KNGMD): reset, MO / M and the file's name are typed, tape
  starts; Play: tape starts at once. Title bar: tape progress, click stops it
