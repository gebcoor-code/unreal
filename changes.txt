Web Unreal Speccy — version history
(web port of UnrealSpeccy 0.39.0)

  [!] - serious bug fixed
  [+] - new feature
  [-] - obsolete feature removed
  [*] - minor fixes
  [@] - feature changed
  [?] - feature added but not yet verified (mostly iPhone / iPad)


        version 0.1.0                   1 oct 2026

+ first web version: UnrealSpeccy 0.39.0 core (Z80, ATM 7.10 memory and
  ports, ATM video modes, WD1793 / Beta 128, AY/YM, beeper) built on
  WebAssembly; Win32 / DirectX layer replaced by a thin web layer
+ unreal.ini; models override keys on top
+ machines: ATM Turbo 2+ 7.10, xBIOS 1.32 XT / LE, ATM Turbo 1, ZX-Evolution,
  Pentagon 128
+ sound through Web Audio (AudioWorklet, ScriptProcessor fallback)
+ disks: TRD, SCL, FDI, UDI, TD0, ISD, PRO, Hobeta, DSK; tapes TAP/TZX/CSW;
  snapshots; zip archives
+ Load window: local files, server list (files.json), URL
+ HDD (IDE) images, cpm.hdd mounted as master
+ General Sound, AY stereo / chip options, sound visualizer
+ on-screen keyboards: XT, ZX (Spectrum+ layout), joystick
+ ATM mode (XT keyboard) switch
+ debugger, Graf Search, File Commander (TR-DOS, CP/M, iS-DOS,
  HDD, RAM disk) with text / hex / Z80 disassembler viewer
+ CPU clock and max speed, pause, reset menu, video filters, palettes
