REST API

model=atm710, xbiosxt, xbios136, atm450, evo, pentagon, scorpion, profi, kay, plus3, quorum, tasis, chic (TASiS / iS-DOS Chic from HDD), nedoos (NedoOS from SD card)
speed=clock: 2 (×3.5 MHz) or 7mhz
a=disk image for A: (path on this site)
hdd=HDD image for HDD 0: zip with image and its .chs, or .hdd (e.g. hdd/cpm.zip)
sd=SD card image for Z-Controller: .img, .vhd or zip with it (e.g. sd/card.zip)
tape= snap=tape or snapshot
autorun=1boot disk in A: (or start tape); not on +3 (no TR-DOS)
press=with autorun: keys for boot menu (0 = first program, enter)
run=start TR-DOS file from disk in A: (BASIC or code)
cpm=ATM CP/M command (atm710, xbiosxt, xbios136, evo): b:alasm; several commands with | between them: b:|dir|alasm (CP/M B: = drive A:, C: = HDD)
xt=1 mute=1ATM mode on; sound off
kbd=on-screen keyboard: zx, xt, joy; off = hidden (the visitor's own setting is not changed)
example?model=pentagon&a=trd/game.trd&run=game

Names

TR-DOS: 8 characters + type; CP/M and iS-DOS: 8.3; FAT: long names (NAME~1.EXT short name is added).

Split files (long file cut into parts with same name): shown as NAME.001, NAME.002…; copy joins them into one file (S3M, MOD, ZIP… by contents, otherwise BIN), except onto TR-DOS. File over 255 sectors copied or put onto TR-DOS is split the same way.

Performance help

Live graphs, updated twice a second. Big number is current value, line below explains it.

Z80 code at

Where Z80 runs its code: 64K address space as 4 banks of 16K (page in each bank is signed), 1K blocks glow by how often program counter is there. Big number: hottest block. Below: share of time in ROM / RAM, busy = part of frame CPU is not halted.

Host

How much of real time this browser spends emulating. Below: milliseconds per emulated frame (20 ms = real time limit).

Memory

RAM as map of 16K pages: written pages glow, pages mapped into Z80 address space now are outlined. Big number: pages written since last update.

Disk

Share of frames with floppy drive busy (reading or writing).

I/O

Z80 port accesses per frame (IN + OUT).

Frames

Emulated frames per second: 50 is real time; red above dashed line = faster than real time (Max speed, turbo).
