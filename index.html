Shows memory as pictures. Width W is in pixels and is rounded to whole bytes: 8 pixels (ZX, VGA), 2 pixels (EGA, 16C) or 1 pixel (256C). Height follows window.
Live view: memory is redrawn 25 times a second while emulator runs; in debugger stopped state is shown.

1 bit per pixel, narrow (640×200)

256C

Compile (sjasmplus)

F9 (Compile) assembles the file under the cursor with sjasmplus: it is the main source, its folder with its subfolders is the project (on any drive: RAM, SD card, HDD, a disk). INCLUDE / INCBIN paths are relative to the including file. The result goes to RAM disk, into the folder named as the main file: the files of SAVEBIN, SAVESNA, SAVETAP, SAVETRD, SAVEHOB, OUTPUT…, the listing (.lst), the labels (.sym) and the messages (.log); files with the same names are replaced. On errors the log opens in the viewer. Copy the result where needed (F5), Enter on .sna / .trd runs it. Upload a project to RAM: Files / Upload Files (a ZIP keeps its folders).

Names

TR-DOS: 8 characters + type; CP/M and iS-DOS: 8.3; FAT: long names (NAME~1.EXT short name is added).

Split files (long file cut into parts with same name): shown as NAME.001, NAME.002…; copy joins them into one file (S3M, MOD, ZIP… by contents, otherwise BIN), except onto TR-DOS. File over 255 sectors copied or put onto TR-DOS is split same way.

Performance help

Live graphs, updated twice a second. Big number is current value, line below explains it.

Z80 code at

Where Z80 runs its code: 64K address space as 4 banks of 16K (page in each bank is signed), 1K blocks glow by how often program counter is there. Big number: hottest block. Below: share of time in ROM / RAM, busy = part of frame CPU is not halted.

Host

How much of real time this browser spends emulating. Below: milliseconds per emulated frame (20 ms = real time limit).

Memory

RAM as map of 16K pages: written pages glow, pages mapped into Z80 address space now are outlined. Big number: pages written since last update.

Disk

Share of frames with floppy drive busy (reading or writing).

I/O

Z80 port accesses per frame (IN + OUT).

Frames

Emulated frames per second: 50 is real time; red above dashed line = faster than real time (Max speed, turbo).

REST API help

  

    
Link to this page with parameters starts a machine as set: index.html?model=pentagon&fdd=a:trd/game.trd&run=game. Parameters may also follow #. Paths are on this site; full URL of another site works when that site allows it (CORS, e.g. raw.githubusercontent.com). What a link sets is not stored: visitor's own settings stay (only sd= switches Z-Controller on).

    
Parameters

    

      
rom=Custom ROM ZIP: machine with its ROM and settings (instead of model=), see below

      
model=atm710, xbios136, atm450, evo, tsconf, pentagon, scorpion, profi, kay, plus3, quorum, tasis, chic (TASiS / iS-DOS Chic from HDD), nedoos (NedoOS from SD card)

      
speed=clock: 2 (×3.5 MHz) or 7mhz; tsconf: 3.5, 7 or 14 (MHz) — the CPU Speed of TS-BIOS (programs may set their own). With speed= the visitor's True clock is off for this visit

      
trueclock=1 / 0True clock on / off for this visit (not stored): the machine's own clock, programs switch its turbo; speed= is not used then

      
fdd=disk image (path on this site) with its drive: a:trd/game.trd or b:trd/work.trd; without drive (fdd=trd/game.trd) goes to A:. Two fdd= for both drives. Path from site root: a:/soft/game.trd. Old a= and b= work too. ATM CP/M works with A: only (its B:)

      
hdd0= hdd1=HDD image for HDD 0 (master) or HDD 1 (slave): zip with image and its .chs, or .hdd (e.g. hdd0=hdd/cpm.zip); hdd= is HDD 0. ATM CP/M works with HDD 0 only (its C:)

      
sd=SD card image for Z-Controller: .img, .vhd or zip with it (e.g. sd/card.zip)

      
tape= snap=tape or snapshot

      
autorun=1start disk in A: (or tape): its boot; disk without boot: its first BASIC program (RUN "name" in TR-DOS, nothing written to disk); Profi with CP/M disk (.PRO): CP/M from FDD; not on +3 (no TR-DOS)

      
autorun=bootas Load / Use boot.b: its boot; disk without boot gets the emulator's boot (boot.b menu, see press=)

      
press=with autorun: keys for menu of the emulator's boot (0 = first program, enter); not sent to a boot of the disk's own

      
run=start TR-DOS file from disk in A: (BASIC or code); no name: as autorun=1

      
cpm=ATM CP/M command (atm710, xbios136, evo): b:alasm; several commands with | between them: b:|dir|alasm (CP/M B: = drive A:, C: = HDD)

      
xt=1 mute=1ATM mode on; sound off

      
swapmouse=1Kempston mouse buttons swapped (as Options / Input / Swap Mouse Buttons), for this visit only

      
kbd=on-screen keyboard: zx, xt, joy; off = hidden (visitor's own setting is not changed)

    

    
rom=: one machine for everyone

    
1. Options / System / Custom ROM: Select ROM, machine, slots (e.g. Quick Commander in 128), Start.
2. Set clock; Options / Disk: Accurate FDD, HDD interface.
3. Save / Custom ROM: ZIP with ROM and its .json.
4. Put ZIP on this site or on GitHub, link: ?rom=rom/my_machine.zip (or rom=https://raw.githubusercontent.com/…/my_machine.zip). Other parameters (fdd=, hdd0=, run=…) work with it.

    
.json in ZIP

    

      
machinePENT128, PENT1024, KAY, SCORPION, PROFSCORP, PROFI, PLUS3, QUORUM, ATM450, ATM710, EVO

      
pagesROM set: 16K page of .rom for each slot (128, sos, dos, sys)

      
resetstart in: auto, SYS, MENU, BASIC, DOS

      
speedclock: 1 = 3.5 MHz … 20 (nearest step is taken)

      
fddaccurate (WD1793 timing, no TR-DOS traps) or fast

      
hddHDD interface: NONE, ATM, NEMO, NEMO-A8, NEMO-DIVIDE, SMUC, PROFI, DIVIDE

      
iniany unreal.ini keys, by section (written by hand): {"BETA128": {"Traps": 0, "Fast": 1, "IL": 2}, "MISC": {"RAMSize": 512}}

    

    
speed, fdd, hdd and ini keys win over what visitor has set in Options, while this machine runs. Order: link, then ZIP, then visitor's settings — speed= in link wins over speed of ZIP; HDD image from hdd= whose .chs has Interface= switches that interface on, over hdd of ZIP. Save / Custom ROM writes speed, fdd and hdd as machine runs now.
